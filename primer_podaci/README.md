# Primer podaci

**Svi podaci u ovom folderu su izmišljeni** i služe samo da se pipeline proba.

- `esco_primer.csv` — 18 veština u istom formatu kao pravi ESCO fajl `skills_en.csv`. ID-evi (`primer:...`) NISU pravi ESCO ID-evi. Za prave rezultate preuzeti ESCO sa https://esco.ec.europa.eu/en/use-esco/download.
- `predmeti.json` — dva izmišljena predmeta sa svim nivoima teksta (opis, ishodi, sadržaj, materijali).
- `oglasi.csv` — tri izmišljena oglasa.
- `test_skup.csv` — izmišljena „ručna“ procena, u formatu koji očekuje evaluacija. Pravi test skup je Ivanin dataset.
